About the Author

My name is Kofi Sarpong, and this project was created for Intro to Web Development. The goal of this website is to explain web development fundamentals while demonstrating responsive and mobile-friendly design.

Project Goals

This website uses one external CSS file, one external JavaScript file, responsive images, a mobile navigation menu, a table, and a quiz form. The layout was tested at multiple screen sizes to make sure it remains readable and usable.
