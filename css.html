CSS: Style and Responsive Layout

CSS changes how HTML looks. It controls color, fonts, spacing, alignment, and the way elements adjust on different screen widths.

Responsive Best Practices

  • Use flexible layouts instead of fixed-width layouts.
  • Set images to max-width: 100% so they shrink on small screens.
  • Use media queries for tablet and phone widths.
  • Make buttons and form controls large enough for touch screens.

Media Query Example

@media (max-width: 768px) {
  .site-nav {
    display: none;
    flex-direction: column;
  }
}
