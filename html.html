HTML: Page Structure

HTML stands for HyperText Markup Language. It is used to organize the content of a webpage so browsers and users can understand the page.

Semantic Elements

Elements like header, nav, main, section, article, and footer describe the purpose of content. They make the page easier to read and more accessible.

Links and Images

Links connect pages together, while images support the written information. Images should always include useful alternative text.

Example HTML

<section>
  <h2>Web Design</h2>
  <p>HTML gives content structure.</p>
</section>
